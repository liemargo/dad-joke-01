The whole entry is one dad joke, sent into a showdown where jokes are judged head-to-head on which one lands the bigger groan. This program's only job is to write that joke to `/output/entry.txt`, which is where the gate picks it up.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
